================================================================================
                        HOW TO FIX (Step-by-Step)
================================================================================

STEP 1: Identify the problem in each DAO file

Look for this pattern at the top of class:

    public class SomeDAO {
        ❌ WRONG:
        Connection c = JDBCUtil.getConnection();  // ← Remove this line!
        
        public int getSomeData() {
            try {
                PreparedStatement pstmt = c.prepareStatement(sql);
                // ... query ...
                // ❌ Resources never closed!
            } catch (SQLException e) { }
        }
    }

STEP 2: FIX - Use try-with-resources instead

    public class SomeDAO {
        // ✅ Remove the class-level connection!
        
        public int getSomeData() {
            String sql = "SELECT ...";
            
            try (Connection c = JDBCUtil.getConnection();
                 PreparedStatement pstmt = c.prepareStatement(sql);
                 ResultSet rs = pstmt.executeQuery()) {
                
                if (rs.next()) {
                    return rs.getInt("ColumnName");
                }
            } catch (SQLException e) {
                e.printStackTrace();
            }
            return 0;
        }
    }

Benefits:
✅ Connection auto-closes when done
✅ Statement auto-closes
✅ ResultSet auto-closes
✅ Even if exception occurs, resources cleaned up

STEP 3: Apply to ALL methods in DAO class

Every method that uses the old `c` connection must be updated.

Pattern:
    // OLD (❌ WRONG)
    public void doSomething() {
        try {
            PreparedStatement pstmt = c.prepareStatement(sql);
            ResultSet rs = pstmt.executeQuery();
            // ...
        } catch (SQLException e) { }
    }

    // NEW (✅ CORRECT)
    public void doSomething() {
        try (Connection c = JDBCUtil.getConnection();
             PreparedStatement pstmt = c.prepareStatement(sql);
             ResultSet rs = pstmt.executeQuery()) {
            // ... use rs here
        } catch (SQLException e) { 
            e.printStackTrace();
        }
    }

        Object[] row = {bus.getListHD().get(i).getId(), ...};  // ← getListHD() called again!

    }

        Object[] row = {list.get(i).getId(), ...};
        model.addRow(row);
    }

       e.printStackTrace();
   }

   try (Connection c = JDBCUtil.getConnection();
